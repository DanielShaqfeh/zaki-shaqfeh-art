# Zaki Shaqfeh Art 🎨 

Welcome to Zaki Shaqfeh Art, a modern web showcase of the artworks of my grandfather Zaki Shaqfeh رحمه الله . <br>
This project celebrates his creativity and artistic journey, presenting his art in a responsive, 
interactive, and visually engaging interface.

## 🌟 Features 

Responsive Design – Works seamlessly on desktop, tablet, and mobile.

Secure Login & Signup – Users can create accounts securely to interact with the site.

About Section – Introduces Zaki Shaqfeh.

Animated Sections – Smooth entrance animations for components.

and more to come.....

## 💻 Technologies Used
### Frontend 

- React.js – For building the interactive UI.

- Tailwind CSS – For modern styling and responsiveness.

- Intersection Observer API – To animate sections as they appear on screen.

- React Router – Smooth navigation for internal pages.

### Backend

- Node.js & Express.js – REST API powering the backend.

- PostgreSQL – Database storing users, artworks, likes, and other data.

- JWT Authentication – Secure login and signup functionality.


## 🚀 Getting Started with the Interface 

### Frontend

1. Clone the repository:
   ```bash
   https://github.com/DanielShaqfeh/zaki-shaqfeh-art.git
   ```
2. Install dependencies 
   ```bash
   cd zaki-shaqfeh-art/frontend
   npm install
   ```
3. Run the frontend
   ```bash
   npm run dev
   ```
